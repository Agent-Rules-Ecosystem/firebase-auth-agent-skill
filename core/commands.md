# ⚡ Comandos de Firebase Auth Skill (`firebase-auth-agent-skill`)

| Comando | Acción | Descripción |
|---|---|---|
| `$firebaseauth` | Bootstrap | Bootstrap de habilidades de Firebase Auth multilenguaje. |
| `$firebaseauth:audit` | Auditoría | Auditoría de almacenamiento de tokens, OAuth fingerprints y Security Rules. |
| `$firebaseauth:rules` | Generación | Genera plantilla estricta de Firestore Security Rules. |
| `$learnskill firebase-auth-agent-skill [propuesta]` | Aprendizaje | Registrar propuesta de mejora para `firebase-auth-agent-skill` en `overview/learning.md` |
| `$revlearnskill` | Revisión | Clasificar e inspeccionar propuestas de aprendizaje acumuladas en `overview/learning.md` |
