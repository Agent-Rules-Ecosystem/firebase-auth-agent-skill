# ⚡ Comandos de Flutter Firebase Auth Agent Skill (`flutter-firebase-auth-agent-skill`)

| Comando | Acción | Descripción |
|---|---|---|
| `$auth` | Bootstrap | Bootstrap de habilidades de autenticación Firebase en Flutter. |
| `$auth:init` | Configuración | Configuración de Firebase Auth, Repository y AuthBloc. |
| `$auth:social` | Integración | Integración de proveedores OAuth (Google, Apple, Microsoft). |
| `$learnskill flutter-firebase-auth-agent-skill [propuesta]` | Aprendizaje | Registrar propuesta de mejora específica para `flutter-firebase-auth-agent-skill` en `overview/learning.md` |
| `$revlearnskill` | Revisión | Clasificar e inspeccionar propuestas de aprendizaje acumuladas en `overview/learning.md` |
