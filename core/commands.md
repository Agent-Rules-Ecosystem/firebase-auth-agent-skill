# ⚡ Comandos de Autenticación ($auth)

- `$auth`: Bootstrap de habilidades de autenticación Firebase.
- `$auth:init`: Configuración de Firebase Auth, Repository y AuthBloc.
- `$auth:social`: Integración de proveedores OAuth (Google, Apple, Microsoft).
- `$auth:rbac`: Configuración de Custom Claims y reglas de seguridad de Firestore.
- `$auth:audit`: Auditoría de manejo de token, expiración y almacenamiento seguro.
- `$auth:test`: Generación de pruebas unitarias de repositorios de autenticación.
